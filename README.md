# Fatture-Grimaldi-App

Controllo mensile della fattura Grimaldi (traghetti Spagna ↔ Italia) per SMET: abbinamento di ogni
riga alle posizioni Showtrip tramite gli imbarchi Intermodale, verifica rispetto al listino e
gestione dei reclami.

Stato: analisi e prototipo dell'abbinamento. Per ripartire leggi [`docs/HANDOFF.md`](docs/HANDOFF.md).
